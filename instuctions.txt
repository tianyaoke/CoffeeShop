# Coffee Shop - Login System

## Setup Instructions

1. Clone: `git clone [url]`
2. Install Node.js 
. Run schema.sql to create users table
 change the details in file `env`mostly the passoword
. `cd backend && npm install`
. `cd frontend && npm install`
. `npm run dev` in backend
. `npm start` in frontend
. Open `http://localhost:3000/login`
NB it should open to this port 3000 or there will be errors as it will not communizate with db
